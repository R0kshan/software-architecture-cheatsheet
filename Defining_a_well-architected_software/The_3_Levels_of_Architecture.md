
| **Level**                               | **Description**                                                                                                                                                                       |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Logical Architecture                    | - Technology-agnostic design<br>- Groups functionalities into coherent functional blocks without technical constraints.                                                               |
| Application Architecture (Software)     | - Software structure<br>- Defines the architectural style (monolith, microservices, EDA), exchange patterns between components, and software choices (frameworks, software solutions) |
| Technical Architecture (Infrastructure) | - Physical implementation<br>- Specifies technical infrastructure choices (Cloud, servers, network zones, security).                                                                  |
