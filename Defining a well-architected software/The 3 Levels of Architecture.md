### 🟦 Logical Architecture
- Technology-agnostic design
- Groups functionalities into coherent functional blocks without technical constraints.
### 🟥 Application Architecture (Software)
- Software structure
- Defines the architectural style (monolith, microservices, EDA), exchange patterns between components, and software choices (frameworks, software solutions).
### 🟧 Technical Architecture (Infrastructure)
- Physical implementation
- Specifies technical infrastructure choices (Cloud, servers, network zones, security).
