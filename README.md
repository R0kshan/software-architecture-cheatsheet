## Software architecture cheatsheet 

> [!NOTE] Note
>  🌳 This is a living document — continuously updated.
### Objective

The knowledge required for software architecture and design is quite vast and it can be overwhelming to navigate different sources or even getting know about the key concepts and knowledge required to make the right decisions. 

Therefore, the **goal** of this repository is to save time  by providing in a **concise manner :** 
- simple, short and easy to understand definitions
- quick access and to a wide variety of software architecture & design concepts as well related patterns & solutions
- best practices
- principles
- common pitfalls
- technology & tools 
- helpful resources that offer a deeper dive in the topic
- case studies of the big systems that we know today
### Who is it for? 

Anyone who wants a concise and quick access to different software architecture & design topics entirely in markdown.

While there are excellent cheatsheets out there, everyone organizes and presents information differently. This motivated me to create my own version tailored for quick, personal reference.
### Contribution
I originally created this for my own reference, but if you find it useful, any contributing and feedback is very welcome !
