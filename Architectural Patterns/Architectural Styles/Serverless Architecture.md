**Definition:** Functions are deployed and executed in an environment managed by a cloud provider.

* **Back-End Frameworks:** Serverless Framework (AWS, Azure, GCP) / Netlify Functions.
* **Front-End Frameworks:** React.js with serverless functions (API integrated via AWS Lambda) / Vue.js or Svelte.
* **API Types:** REST (most common for endpoints) / GraphQL (rich interactions).
* **Advantages:** Cost reduction (pay-per-use) / No infrastructure management.
* **Disadvantages:** Function start times (cold start) / Vendor lock-in.
* **Target Audience:** Startups or small businesses looking for cost and management reduction.
* **Market Position:** Peak of inflated expectations (25% adoption and growing).

### Market Insights 
* **Editors**: AWS Lambda, Google Cloud Functions, Azure Functions.
